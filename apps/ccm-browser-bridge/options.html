CCM Browser Bridge

This extension opens Medical Bay's connected accounts in the browser profile where it is installed, and verifies that each request really came from CCM.

1. Point the extension at CCM

2. Copy this instance id into CCM

In CCM, open Account Launcher → Set up account launching and paste the id below. CCM uses it to map this browser profile to your accounts.

…

What this extension does not do

  • It never asks for access to cookies, browsing history, passwords or form data.
  • It never signs in to a provider on your behalf, and never bypasses MFA or a CAPTCHA.
  • It refuses to open any address that is not on the provider allowlist.
  • A valid API connection does not imply a signed-in browser session; the provider decides that.
